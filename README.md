## 🚀 Proyectos públicos

### 🎬 [Snipra Video](https://github.com/kerwilgil/snipra-video)
**Editor y procesador de video local-first.** Convierte material en clips, subtítulos y composiciones, con análisis asistido por IA opcional y extensión para navegadores Chromium.

- **Stack:** Python, FastAPI, React, TypeScript, FFmpeg y SQLite.
- **Funciones:** ingesta de medios, procesamiento y exportación de clips, catálogo dinámico NVIDIA NIM y flujos de trabajo locales.
- **Estado:** **código fuente público** · Sin release binaria oficial por ahora · [Repositorio y capturas](https://github.com/kerwilgil/snipra-video) · [Caso de estudio de IA](https://github.com/kerwilgil/snipra-video/blob/main/docs/AI_CASE_STUDY.md).

### 📡 [TRAZIP](https://github.com/kerwilgil/trazip-network)
**Herramienta de escritorio para diagnóstico y análisis defensivo de redes y VoIP.** Integra análisis de tráfico, capturas PCAP, inteligencia de red y herramientas para investigación técnica.

- **Stack:** Go, Wails, React y TypeScript.
- **Funciones:** conectividad, PCAP/PCAPNG, DNS, BGP, OSINT y análisis SIP/RTP, según capacidades de la plataforma.
- **Última versión estable:** **v1.0.0 (Windows x64)** · [Release oficial](https://github.com/kerwilgil/trazip-network/releases/tag/v1.0.0) · [Instalador Setup](https://github.com/kerwilgil/trazip-network/releases/download/v1.0.0/TRAZIP-1.0.0-Setup.exe) · [Portable ZIP](https://github.com/kerwilgil/trazip-network/releases/download/v1.0.0/TRAZIP-1.0.0-portable.zip).

### 🎵 [PlaylistAI](https://github.com/kerwilgil/PlaylistAI)
**Generador y analizador de playlists para Spotify mediante IA.** Convierte ideas, estados de ánimo o conceptos en listas de reproducción con canciones verificadas contra el catálogo real.

- **Stack:** Python, Flask, Spotipy / Spotify Web API, OpenAI y NVIDIA NIM, entre otros proveedores.
- **Funciones:** creación y análisis de playlists, validación de canciones, catálogos dinámicos de modelos OpenAI/NVIDIA, selector accesible y ejecución local. Los tokens de Spotify se mantienen en memoria del servidor.
- **Última versión estable:** **v1.2.0 (Windows x64)** · [Código fuente](https://github.com/kerwilgil/PlaylistAI) · [Descargar v1.2.0](https://github.com/kerwilgil/PlaylistAI/releases/tag/v1.2.0) · [ZIP Windows](https://github.com/kerwilgil/PlaylistAI/releases/download/v1.2.0/PlaylistAI-1.2.0-Windows-x64.zip).

### 💰 [Moneta Lite](https://github.com/kerwilgil/moneta-lite)
**Gestor de finanzas personales self-hosted y de código abierto.** Administra cuentas, movimientos, facturas, tarjetas y suscripciones sin depender de una plataforma SaaS.

- **Stack:** Python, Django 6, SQLite / PostgreSQL.
- **Funciones:** panel financiero, reportes, cola de importaciones con deduplicación y servidor MCP para agentes con aprobación humana.
- **Versión documentada:** **v0.3.0** · [Código y documentación](https://github.com/kerwilgil/moneta-lite).

### 🎬 [DaVinci Resolve MCP](https://github.com/kerwilgil/davinci-resolve-mcp)
**Servidor MCP para automatizar DaVinci Resolve** mediante herramientas estructuradas, sin depender de clics o automatización visual de la interfaz.

- **Stack:** Python, Model Context Protocol (MCP), API de DaVinci Resolve.
- **Funciones:** inspección de proyectos, edición de timelines, gestión de medios, operaciones de color y renders.
- **Enfoque:** ejecución local, separación de lectura/escritura y pruebas automatizadas.
